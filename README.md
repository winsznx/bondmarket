# BondMarket

Peer-to-peer bond issuance and trading platform on Base and Stacks blockchains.

## Features

- Issue bonds with custom terms
- Transfer bonds to other users
- Interest rate management
- Maturity date tracking
- Repayment mechanism

## Tech Stack

- **Frontend**: Next.js 14, TypeScript, Tailwind CSS
- **Base**: Solidity 0.8.20, Foundry, Reown wallet
- **Stacks**: Clarity v4, Clarinet, @stacks/connect

## Getting Started

```bash
pnpm install
pnpm dev
```
